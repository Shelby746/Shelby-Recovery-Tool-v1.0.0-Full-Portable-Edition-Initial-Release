📌 About

Shelby Recovery Tool is a Windows-based Android device servicing and recovery toolkit designed to simplify device management, firmware flashing and recovery operations.

This repository contains the source code, development resources, supporting utilities and project documentation for Shelby Recovery Tool.

✨ Features

- ⚡ MediaTek Flash Tool — Scatter-based firmware flashing support.
- 📱 ADB Tools — Android Debug Bridge device detection and commands.
- 🔧 Fastboot Tools — Device detection and GETVAR information.
- 💾 Partition Management — Partition-related operations.
- 📦 Portable Application — Windows application resources.
- 🛠️ Driver Support — MediaTek and Transsion USB drivers.
- 💻 Development Resources — Supporting scripts, dependencies and utilities.

📂 Repository Contents

This repository includes:

- Source — Application source files.
- Tool — Application binaries and supporting resources.
- tools — Development scripts and utilities.
- README.md — Project documentation.
